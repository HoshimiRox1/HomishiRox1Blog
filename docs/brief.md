# Roxy Blog 产品简介

## 1. 产品定位

Roxy Blog 是一个以“帅、酷炫、强视觉动效”为第一印象的个人网站。它不是传统博客首页，也不是作品简历模板，而是一个结合动漫视觉、个人档案、作品展示、笔记收藏和 BGM 氛围的个人主页。

网站第一阶段重点是做出主页面和全站切换骨架：用户进入后先看到高对比大标题、小字内容和底部滚动文字；继续滚轮后，文字缩小移动到左上角，动漫角色从右侧手风琴区域滑入舞台；桌面端右侧常驻 FEED 式竖向色带手风琴，用于切换 Home、Profile、Portfolio、Blog 四个板块；窄屏端隐藏右侧手风琴，改用底部 Menu 打开四色全屏菜单。

## 2. 视觉方向

- 主气质：黑白高对比海报感，强调大字、强构图、清晰动势。
- 配色系统：借鉴包豪斯风格，使用米白、黑、红、黄、蓝作为基础色。
- 动效参考：借鉴 FEED Agency 的右侧竖向色带手风琴结构，但不沿用其配色和品牌元素。
- 动漫角色：角色是 Home 内部视觉内容，不用于全站板块切换。
- 风格边界：避免纯黑白全站导致单调；红黄蓝用于功能色、切换色、进度色和作品页擦除色块。

### 配色规范

Phase 1 使用包豪斯基础色，不沿用 FEED Agency 的橙粉/青绿品牌色。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主黑 | `#090909` | 首页背景、大标题对比、粗边框、重要文字 |
| 米白 | `#FBF5E7` | 内容页底色、反白文字区、手风琴悬浮底色 |
| 红 | `#E30613` | Profile 色带、警示/强调、局部几何色块 |
| 黄 | `#FFCC00` | Portfolio 色带、作品页 wipe、进度提示 |
| 蓝 | `#0047AB` | Blog 色带、信息区、次级强调 |
| 冷灰 | `#D8D0C5` | 小字、辅助说明、弱化文本 |

使用规则：

- 黑白负责“帅”和海报感，红黄蓝负责交互状态和板块识别。
- 红黄蓝不大面积同时铺开，避免页面变成杂乱拼色。
- 右侧手风琴色带默认按 `Home=黑`、`Profile=红`、`Portfolio=黄`、`Blog=蓝`，避免 Home 默认态和近白悬浮态撞色。
- BGM、按钮、进度、作品切换等组件可以引用红黄蓝，但每个组件只选一个主色。
- 如果角色图本身颜色很强，背景几何色块需要降权，优先保证角色清晰。

## 3. Phase 1 范围

Phase 1 只实现主页面与全站骨架，不深入制作 Profile、Portfolio、Blog 的完整内容。

### Home

- 初始首屏只显示大标题、小字内容和底部滚动文字，不展示角色。
- 滚轮后标题缩小并滑动到左上方，小字内容转为说明信息。
- 角色从右侧手风琴区域向左滑入。
- 多次滚轮可以切换角色。
- 一次滚轮手势无论滚动距离多长，只切换一个角色；动画期间锁定切换，只有明确的下一次滚轮手势才进入下一个角色。
- 角色切换采用首尾循环：向下滚动到最后一个角色后，再次下滚从第一个角色重新入场；向上滚动可回到上一个角色。
- 第一阶段接入 `waifus/珂莱塔-cutout.png` 和 `waifus/洛琪希-cutout.png` 两个已处理角色图。

### 右侧手风琴

- 顺序固定为：Home、Profile、Portfolio、Blog。
- 结构为 FEED 式右侧并排竖向色带，每条色带贯穿全屏高度。
- 文字旋转显示在色带底部区域，字底朝向右侧竖条边缘，并贴近各自色带右边缘；四条文字保持同一水平线，底部留白约 50px。
- 悬浮态使用近白底和对应板块色文字；不保留当前页面高亮状态，不加下划线，不做悬浮位移。
- 桌面端点击某个色带时，真实右侧竖条上的四个文字节点按顺序直接滑出屏幕，不做透明度渐隐；文字全部离开后，四色克隆轨道从右侧原位等比横向扩张铺满屏幕，黑边保持固定宽度；完成页面切换后缩回右侧原位，原文字节点再按反向顺序滑回。
- 窄屏端右侧手风琴隐藏，底部显示 Menu 按钮；点击 Menu 后四条竖条从上往下、按 Home / Profile / Portfolio / Blog 顺序依次滑入，并停在底部 Menu 按钮上方；点击板块后四条竖条从左到右依次上滑消失，退出完成后切换页面。
- Phase 1 中 Profile、Portfolio、Blog 只进入占位页。

### BGM 播放器

- 全站固定左下角。
- 在 Home 页面时，播放器位于底部滚动文字框上方，避免遮挡 marquee。
- 在其他页面时保持左下角固定。
- 浏览器自动播放限制下，BGM 需要由用户主动触发播放。

## 4. Phase 1 之外的待完善内容

- Portfolio 页面：每个作品占据主要视野，滚轮时纯色色块从底部上滑铺满，再切换到下一个作品。
- Profile 页面：个人简介、喜好、联系方式、GitHub 等内容的包豪斯档案卡布局。
- Blog 页面：博客笔记、番剧记录、电影记录、游戏记录四个大板块的书架/收藏库结构。
- 角色系统：最终补齐 5 个动漫角色 IP，确认角色顺序、标题文案、配色和切换节奏。
- BGM 系统：曲目列表、播放策略、音量控制、曲目信息展示和状态持久化。

## 5. 成功标准

- 首页第一眼足够帅、酷炫，有明确的海报式冲击力。
- 右侧手风琴的结构和展开动势清楚，能成为全站导航的核心记忆点。
- Home 内角色滚轮切换有分镜感，而不是滚动距离驱动的机械滚动。
- 包豪斯颜色服务功能和转场，不变成随意装饰。
- Phase 1 的占位页能为后续 Profile、Portfolio、Blog 扩展保留清晰入口。
