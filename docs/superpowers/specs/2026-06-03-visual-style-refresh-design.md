# Visual Style Refresh Design - Fresh Brutalist Stage

## 1. 目标

将 Roxy Blog 的 Phase 1 视觉方向从“包豪斯三原色”调整为“清爽新粗野主义海报 + 圆角 HUD 展示系统”。

本设计只锁定风格语言和视觉规则，不改变当前 Phase 1 的交互骨架：

- Home 首屏仍然是第一眼视觉核心。
- 右侧竖条手风琴仍然是全站主导航。
- Home 内滚轮角色切换、BGM 播放器、底部 marquee 和占位页结构继续保留。
- Profile / Portfolio / Blog 的正式内容仍然属于后续独立 spec。

## 2. 设计原则

### 清爽新粗野主义

新粗野主义在本项目里不等于“所有元素必须硬矩形”。它的核心是：

- 粗边框和明确边界。
- 大字号、直接排版和强视觉层级。
- 轻微错位、硬阴影或明显拼接感。
- 不追求玻璃态、霓虹、柔和渐变或过度精致。
- 用清爽配色制造反差，而不是沿用红黄蓝三原色限制。

### 圆角与硬矩形并存

主界面当前风格基本锁定为：

- 大结构可以继续硬朗，例如右侧竖条、底部 marquee、主标题构图。
- 内容模块可以使用圆角，例如角色信息卡、BGM、标签、Profile/Blog 未来的信息组件。
- 圆角不是强制规范；当硬矩形在某个位置更有力量、更好看时，可以使用硬矩形。
- 后续页面或组件如果有明显视觉分歧，应先做小 mockup 给用户确认，再写入最终实现。

## 3. 配色方向

基础气质从黑白红黄蓝改为冷白底色、黑色粗边和清爽糖果色点缀。

建议色板：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主墨黑 | `#111111` | 粗边框、强文字、底部 marquee、硬阴影 |
| 冷白 | `#F7FBFF` | Home 主背景 |
| 纸白 | `#FFFFFF` | 卡片、标签、HUD 模块底色 |
| 淡紫藤 | `#D8CCFF` | Home 竖条主色 |
| 浅青 | `#B9F5FF` | Profile 或信息辅助色 |
| 奶黄 | `#FFE7A6` | Portfolio / Work 竖条或强调块 |
| 嫩绿 | `#C7F2D4` | Blog 竖条主色 |
| 浅粉 | `#FFD6E8` | 角色舞台或视觉焦点底色 |
| 动作粉 | `#FF7AA8` | BGM、按钮、局部强强调 |
| 薄荷 | `#D7FFF1` | 标签、状态、轻强调 |

右侧竖条初步建议：

- Home：淡紫藤 `#D8CCFF`，避免白底黑字和 hover 态冲突，也避免和 Blog 绿系接近。
- Profile：浅青 `#B9F5FF`。
- Portfolio / Work：奶黄 `#FFE7A6`。
- Blog：嫩绿 `#C7F2D4`。

悬浮态规则：

- 竖条 hover 可以统一使用白底。
- hover 文字不使用黑色默认值，而使用对应板块的深色强调色。
- Home hover 文字建议使用深紫，例如 `#6B4DFF`。
- hover 态必须避免和默认态撞色，尤其不能出现 Home 默认白底黑字。

## 4. Home 主界面

Home 主界面已确认采用“Fresh Brutalist Stage”方向。

核心构图：

- 冷白或极浅冷色背景。
- 黑色粗边框网格或低透明辅助线作为结构背景。
- 左侧大标题 `ROXY BLOG` 保留海报级冲击力。
- 标题下方使用粗边圆角说明卡，而不是大段普通正文。
- 右侧角色舞台使用清爽色块、粗边框和适度圆角。
- 左下角 BGM 使用小型圆角 HUD 模块。
- 底部 marquee 可继续使用黑底白字，提供压场感。
- 右侧竖条保留贯穿全高的硬结构，作为全站导航记忆点。

参考 mockup：

- `visual-style-hybrid-mockup.html`

该 mockup 作为后续风格替换的示意图保留。实现时不需要逐像素复刻，但需要保留它确认过的整体气质：清爽底色、黑色粗边、淡紫 Home 竖条、圆角 HUD 信息模块和强海报标题。

## 5. 组件规则

### 角色舞台

- 可以使用浅粉或其他清爽色作为角色背板。
- 角色背板允许圆角，避免全页面全是硬矩形。
- 角色信息卡使用粗边圆角 HUD 风格。
- 角色图优先保持清晰，背景色块不能抢角色。

### BGM 播放器

- 保持左下角固定。
- 使用白底、黑粗边、圆角和小面积动作粉按钮。
- Home 页面仍需要避开底部 marquee。

### 标签和小信息条

- 可以使用胶囊圆角或小圆角矩形。
- 标签适合使用薄荷、白底、浅青等轻色。
- 文案保持短、硬、直接。

### 占位页

- Profile / Portfolio / Blog 在 Phase 1 仍是占位页。
- 视觉上应逐步从旧包豪斯色块迁移到新色板。
- 正式内容页需要单独设计，不在本 spec 内展开。

## 6. 不做什么

本次风格重构不做：

- 不引入新框架、UI 库、后端、CMS 或数据库。
- 不重写路由、角色滚轮逻辑或页面转场架构。
- 不把所有元素统一改成圆角。
- 不把所有元素统一改成硬矩形。
- 不使用渐变、玻璃态、霓虹、复杂阴影或装饰性大色块堆叠。
- 不继续受限于包豪斯红黄蓝三原色。

## 7. 验收标准

视觉验收：

- 第一眼仍然有“帅、酷炫、强视觉”的主页冲击。
- 配色明显比旧包豪斯三原色更清爽、更自由。
- Home 竖条默认态不与 hover 白底态冲突。
- 页面不因过多硬矩形产生审美疲劳。
- 圆角模块不会削弱新粗野主义的粗边框和强结构感。

交互验收：

- 右侧竖条导航、页面转场、移动端菜单仍可用。
- Home 滚轮角色切换仍保持一次手势切换一个角色。
- BGM 不遮挡底部 marquee。

实现验收：

- 改动后运行构建。
- 对桌面和移动视口做浏览器可见验证。
- 动效任务必须确认实际可见运动和布局遮挡，而不是只检查代码存在。
