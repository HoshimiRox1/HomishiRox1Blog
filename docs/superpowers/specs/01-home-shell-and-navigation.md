# Spec 01 - Home Shell and Navigation

## 1. 目标

实现 Roxy Blog 的第一阶段主页面与全站骨架，让网站具备明确的第一眼视觉记忆和可继续扩展的页面结构。

Spec 01 聚焦：

- Home 首屏视觉。
- Home 内滚轮角色切换。
- 右侧 FEED 式包豪斯色带手风琴。
- Profile / Portfolio / Blog 占位页。
- 全站 BGM 播放器基础形态。

## 2. 不做什么

本 spec 不实现：

- Portfolio 完整作品数据和滚动擦除切换。
- Profile 完整个人档案内容。
- Blog 四类书架内容系统。
- 5 个角色 IP 的完整素材系统。
- Astro 迁移、内容集合、CMS、后端或数据库。

## 3. 页面结构

### Home

Home 是 Phase 1 的核心页面。

初始状态：

- 只展示大标题、小字内容和底部滚动文字。
- 不展示角色。
- 右侧手风琴常驻可见。
- BGM 播放器位于左下角，并在底部滚动文字上方。

滚轮后状态：

- 大标题缩小并滑动到左上方。
- 小字内容变成辅助说明。
- 当前角色从右侧手风琴区域向左滑入舞台。
- 后续滚轮可切换到下一个角色。

### ProfilePlaceholder

- 通过右侧 Profile 色带进入。
- Phase 1 只展示占位标题和一句说明。
- 视觉上仍保留右侧手风琴和 BGM 播放器。

### PortfolioPlaceholder

- 通过右侧 Portfolio 色带进入。
- Phase 1 只展示占位标题和一句说明。
- 文案需要提示后续将实现作品滚动擦除切换。

### BlogPlaceholder

- 通过右侧 Blog 色带进入。
- Phase 1 只展示占位标题和四个未来板块名称：博客笔记、番剧记录、电影记录、游戏记录。

## 4. 右侧手风琴

右侧手风琴是全站唯一主要板块导航。

结构要求：

- 采用 FEED 式右侧并排竖向色带结构。
- 四条色带从左到右或右侧区域内并排显示。
- 每条色带贯穿全屏高度。
- 每条色带底部显示旋转 90 度的大字。
- 顺序固定为：Home、Profile、Portfolio、Blog。

配色：

- Home：米白 `#FBF5E7`。
- Profile：红 `#E30613`。
- Portfolio：黄 `#FFCC00`。
- Blog：蓝 `#0047AB`。
- 主黑：`#090909` 用于背景、边框和高对比文字。

交互：

- 点击某个色带后，该色带横向展开并铺满屏幕。
- 展开完成后切换到对应页面状态。
- 页面加载/状态切换完成后，色带缩回右侧手风琴。
- 当前页面对应色带需要有 active 状态。
- hover 和 active 状态只作用于旋转文字：文字轻微悬浮并出现少量阴影，不加下划线，不移动、放大、滤镜高亮或遮罩处理整条色带本体，避免破坏四条竖带的稳定布局。

## 5. Home 角色滚轮切换

角色切换采用滚轮手势锁，不按滚动距离连续推进。

规则：

- 一次滚轮手势无论 `deltaY` 多大，只触发一次角色切换。
- 动画执行期间进入锁定状态，不接受下一次切换。
- 锁定时间以动画完成为准，建议初始为 `700ms-1000ms`。
- 只有明确的下一次滚轮动作才切换到下一个角色。
- 向下滚动切到下一个角色，向上滚动切到上一个角色。
- 到达末尾角色后继续向下滚动时，切回第一个角色并从右侧重新入场。
- 到达第一个角色后向上滚动时，切回最后一个角色。
- 首尾循环不是倒放上一段动画，而是按下一次角色入场处理。

初始素材：

- `waifus/珂莱塔-cutout.png`
- `waifus/洛琪希-cutout.png`

后续素材：

- 最终目标是 5 个动漫角色 IP，但不在 Spec 01 内补齐。

## 6. BGM 播放器

位置：

- 全站固定左下角。
- Home 页面时放在底部滚动文字框上方，避免遮挡。
- 其他页面保持左下角。

功能：

- 播放 / 暂停。
- 显示当前播放状态。
- Phase 1 可先使用占位曲目或无音频占位 UI。
- 浏览器自动播放限制下，必须由用户主动触发播放。

视觉：

- 使用包豪斯组件风格。
- 黑色粗边框。
- 可使用红、黄、蓝中的一个作为强调色，但不要同时混用多个主色。

## 7. 动效要求

必须使用 GSAP 管理核心动效。

核心动效：

- Home 标题缩放并移动到左上角。
- 角色从右侧滑入。
- 底部文字无缝滚动。
- 右侧色带展开铺屏与缩回。
- 页面占位内容入场。

实现注意：

- 不把 GSAP timeline 和 React 状态反复重建绑定在一起。
- timeline 应该通过 ref 或局部上下文稳定管理。
- 需要尊重 `prefers-reduced-motion`，提供弱动效或无动效退路。

## 8. 组件边界

建议组件：

- `AppShell`
- `HomePage`
- `SidebarAccordion`
- `CharacterStage`
- `MarqueeBar`
- `BgmPlayer`
- `PlaceholderPage`
- `PageTransitionOverlay`

建议数据：

- `pages`：Home / Profile / Portfolio / Blog 的标题、颜色、占位文案。
- `characters`：角色名称、图片路径、标题文案、辅助色。

## 9. 验收标准

功能验收：

- 进入网站后默认显示 Home 初始首屏。
- Home 初始首屏不展示角色。
- 滚轮一次只切换一个角色。
- 角色切换动画期间不能被连续滚轮打断。
- 右侧四条色带可见，顺序为 Home、Profile、Portfolio、Blog。
- 点击 Profile / Portfolio / Blog 能看到色带铺屏转场，并进入对应占位页。
- BGM 播放器在 Home 不遮挡底部滚动文字。

视觉验收：

- 首页第一眼有黑白高对比海报感。
- 手风琴结构接近 FEED 的右侧并排竖向色带，但使用包豪斯配色。
- 红黄蓝用于板块识别和交互状态，不变成杂乱装饰。
- 角色图清晰，不被底部 marquee 或手风琴不合理遮挡。

技术验收：

- `npm run build` 通过。
- 本地浏览器预览无黑屏。
- 桌面视口下主要动效可见。
- 窄屏下有可接受的手风琴降级方案。
