# BGM Player

## 模块性质

- 类型：全站通用组件。
- 实现状态：三首真实音频、展开抽屉、图标控制、线状进度/音量、默认 10% 自动播放尝试和状态持久化已实现。
- 冻结状态：组件职责和紧凑 HUD 形态稳定；正式专辑封面待用户补齐。

## 模块功能

BGM 播放器常驻全站左下角。收起态显示图标播放按钮、当前歌名、可选作者和状态；点击卡片空白区域后，详情抽屉从底卡背后向上滑出，提供图标切歌、线状进度和独立竖向音量控制。

- `title`
- 可选 `artist`
- `src`
- `cover`

## 播放行为

- 浏览器首次进入时默认音量为 `10%`，并尽力调用 `audio.play()` 自动播放。
- 若浏览器拦截有声自动播放，播放器保持暂停并显示 `tap play`；已有本地音量优先于默认值恢复。
- 上一首、下一首首尾循环。
- 播放中切歌会继续播放；暂停时切歌保持暂停。
- 单曲结束自动播放下一首，最后一首回到第一首。
- `audio.play()` 被浏览器拒绝时回到暂停并显示 `tap play`。
- 音频加载失败时显示 `audio unavailable`，不自动连续跳过坏曲目。
- 作者缺失时隐藏作者行；封面失败时显示 `NO ART`。

## 持久化

播放器使用 `roxy-bgm:v1` 保存：

- 当前曲目 id。
- 音量。
- 当前播放位置。

刷新后恢复以上数据，但不会恢复自动播放状态。无效曲目、非法数值和损坏 JSON 会回退到安全默认值。

## 动画与交互

- 展开顺序：收起文案右滑渐隐、播放图标居中、上一首/下一首从其背后向两侧展开、详情抽屉在裁切视窗内从底卡背后向上滑出。
- 收起使用同一条 GSAP timeline 的 `reverse()`，保证严格反序。
- 展开和音量时间线各自使用显式交互锁，动画期间忽略重复状态切换。
- 详情面板只保留顶部圆角，下缘以直边和左右竖线连接底卡；右侧硬阴影与底卡阴影对齐，底卡始终位于抽屉前景，避免滑出穿帮。
- 封面槽固定在详情头部最右端，使用无圆角硬矩形。
- 音量图标按钮使用细黑边圆角矩形；打开后封面向左移动，封面右边缘与进度条右侧时间文字右边缘对齐，为原封面槽位内显现的黑色竖轨、粉色音量线、黑边粉心滑块和百分比文本让位。
- 进度条使用黑色细轨、粉色已播放线和黑边粉心滑块，不使用容器式进度槽。
- 所有控制图标使用组件内联 SVG，不引入图标依赖；播放、切歌、进度和音量控件不会触发卡片展开。
- `prefers-reduced-motion` 下直接切换最终布局状态。

## 响应式行为

- 桌面宽度为 `220px`，展开总高度约 `160px`。
- 手机宽度为 `206px`，展开总高度约 `155px`。
- Home 页面位于 marquee 上方，移动端同时避开底部 Menu。
- 播放器展开时 Home 提示轨按桌面、平板和手机空间上移，避免与抽屉重叠。
