# BGM Player

## 模块性质

- 类型：全站通用组件。
- 实现状态：真实多曲目播放逻辑、展开抽屉、音量控制和状态持久化已实现。
- 冻结状态：组件职责和紧凑 HUD 形态稳定；正式曲目素材与元数据待用户补齐。

## 模块功能

BGM 播放器常驻全站左下角。收起态显示播放按钮、当前歌名、可选作者和状态；点击卡片空白区域后展开紧凑详情抽屉，提供上一首、下一首、进度和独立竖向音量控制。

## 曲目与素材合同

`src/data/bgm.js` 当前声明三首曲目，字段为：

- `id`
- `title`
- 可选 `artist`
- `src`
- `cover`

正式素材路径约定为：

- `public/assets/bgm/track-01.mp3` 至 `track-03.mp3`
- `public/assets/bgm/track-01.webp` 至 `track-03.webp`

仓库当前未包含这些音频和封面，因此本地运行会进入 `audio unavailable` / `NO ART` 回退状态。补齐素材和真实曲目信息后无需修改组件结构。

## 播放行为

- 浏览器首次进入时保持暂停，只响应用户主动点击 PLAY。
- 上一首、下一首首尾循环。
- 播放中切歌会继续播放；暂停时切歌保持暂停。
- 单曲结束自动播放下一首，最后一首回到第一首。
- `audio.play()` 被浏览器拒绝时回到暂停并显示 `tap play`。
- 音频加载失败时显示 `audio unavailable`，不自动连续跳过坏曲目。
- 作者缺失时隐藏作者行；封面失败时显示 `NO ART`。

## 持久化

播放器使用 `roxy-bgm:v1` 保存：

- 当前曲目 id。
- 音量。
- 当前播放位置。

刷新后恢复以上数据，但不会恢复自动播放状态。无效曲目、非法数值和损坏 JSON 会回退到安全默认值。

## 动画与交互

- 展开顺序：收起文案右滑渐隐、PLAY 居中、PREV/NEXT 从 PLAY 背后向两侧展开、详情抽屉向上滑出。
- 收起使用同一条 GSAP timeline 的 `reverse()`，保证严格反序。
- 展开和音量时间线各自使用显式交互锁，动画期间忽略重复状态切换。
- 音量按钮打开独立右侧音量区：封面轻微左移，遮罩从下向上显现竖向轨道、粉色音量值和圆形滑块。
- PLAY、切歌、进度和音量控件不会触发卡片展开。
- `prefers-reduced-motion` 下直接切换最终布局状态。

## 响应式行为

- 桌面宽度为 `220px`，展开总高度约 `160px`。
- 手机宽度为 `206px`，展开总高度约 `155px`。
- Home 页面位于 marquee 上方，移动端同时避开底部 Menu。
- 播放器展开时 Home 提示轨按桌面、平板和手机空间上移，避免与抽屉重叠。
